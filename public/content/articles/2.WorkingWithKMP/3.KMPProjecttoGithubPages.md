1. Follow tutorial
https://www.jetbrains.com/help/kotlin-multiplatform-dev/multiplatform-publish-apps.html#web-app

2. /docs contains the files that were generated from running the wasmJSBrowserDistribution (all files that were located in the productionExecutable).

3. select deploy from branch in github pages settings and choose /docs.
